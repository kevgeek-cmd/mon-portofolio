## Brand & Style

This design system embodies the aura of high-caliber digital craftsmanship, blending editorial precision with cinematic warmth. Crafted for an elite Product Builder, UI/UX Designer, and AI Architect, the aesthetic communicates mastery, forward-looking technical innovation, and luxury restraint.

### Design Principles
- **Cinematic Radiance:** Deep, velvety carbon foundations (#090909) illuminated by diffused warm amber backlights (#FF7A00). The contrast evokes the dramatic rim lighting of high-end studio photography.
- **Glassmorphic Precision:** Floating pill containers, micro-translucencies, and ultra-fine hairline strokes (1px rgba(255, 255, 255, 0.08)) create palpable physical layers without visual clutter.
- **Intentional Restraint:** Space is generous and deliberate. Typography commands attention through stark size and weight contrasts—pairing bold condensed display forms with clean, razor-sharp geometric body text.
- **Fluid Tactical Interactions:** Tactile feedback, seamless micro-spring transitions, and magnetic hover glows on interactive pill elements convey sophistication and bespoke engineering.

## Colors

The palette leverages a controlled spectrum of deep blacks and radiant ambers, engineered strictly for high-end dark mode environments.

### Core Swatches
- **Primary Amber (`#FF7A00`):** The signature accent used for primary CTAs, highlight badges, active states, and focal brand glyphs. Supported by a lighter gradient edge (`#FF9933`).
- **Surface Foundations:**
  - **Base Canvas (`#090909`):** The primary background tone, grounding the viewport in deep studio darkness.
  - **Elevated Canvas (`#0E0E0E` / `#141414`):** Substrate for cards and floating elements.
  - **Glass Shells (`rgba(25, 25, 25, 0.55)`): Semi-translucent panels backed by backdrop filters.
- **Typography & Details:**
  - **Primary Text (`#F5F5F5`):** Pristine optical white with slight warmth to prevent harsh glare.
  - **Secondary Text (`#A0A0A0`):** Muted cool gray for subheads, meta tags, and body paragraphs.
  - **Subtle Hairlines (`rgba(255, 255, 255, 0.08)` to `rgba(255, 122, 0, 0.2)`): Defining structural perimeters.
- **Atmospheric Glow:** Diffuse radial gradients (`radial-gradient(circle, rgba(255, 122, 0, 0.22) 0%, rgba(9, 9, 9, 0) 70%)`) placed behind key imagery and hero portraits.

## Typography

Typography pairs **Plus Jakarta Sans** for editorial confidence and human warmth with **Space Grotesk** for technical, high-precision metadata.

### Typographic Rhythm
- **Hero Title Dynamic:** Features high-contrast emphasis; the creator's name shifts into an assertive italicized amber (`Hi, I'm Kevin.`), anchoring the page.
- **Eyebrows & Metadata:** Rendered in Space Grotesk in all-caps with generous character spacing (`0.14em`), communicating engineering rigor (e.g., `PRODUCT BUILDER • UI/UX DESIGNER • AI BUILDER`).
- **Body Text:** Maintained at generous line heights (`1.5` to `1.6`) to maintain legibility against dark, light-emitting surfaces.

## Layout & Spacing

The layout is built on an adaptive 12-column grid framed within a container capped at 1440px.

### Breakpoints & Adaptation
- **Desktop (1024px+):** Asymmetrical 2-column split. Left column anchors visual portraiture and atmospheric backlight; right column hosts hero headlines, pills, descriptions, action clusters, and horizontal metric shelves. Fixed vertical social dock affixed to the outer left margin.
- **Tablet (768px – 1023px):** Portrait scales gracefully; hero text consolidates; primary nav compresses into a frosted floating capsule.
- **Mobile (&lt; 768px):** Single-column stacked order. Portrait anchors top with a subtle backdrop halo, followed sequentially by status badges, primary statement, CTA pill groups, and stacked stats. Social anchors shift to a floating bottom sheet or horizontal cluster.

## Elevation & Depth

Visual depth is established through a combination of optical luminescence and physical glass mechanics rather than traditional dropped drop-shadows.

### Layer Hierarchy
1. **Base Layer (Elevation 0):** Pure `#090909` backcloth with soft radial ambient glow cones (`rgba(255, 122, 0, 0.15)` to `rgba(255, 122, 0, 0.02)`) focused behind hero assets.
2. **Glass Layer (Elevation 1):** Floating capsules, navigation bars, and secondary buttons built with `background: rgba(22, 22, 22, 0.65)`, `backdrop-filter: blur(20px)`, and a 1px composite outline (`border: 1px solid rgba(255, 255, 255, 0.08)`).
3. **Primary Interactive Layer (Elevation 2):** Primary action buttons rendered in solid `#FF7A00` with an outer directional halo: `box-shadow: 0px 10px 30px rgba(255, 122, 0, 0.35), 0px 2px 6px rgba(255, 122, 0, 0.2)`.
4. **Docked Vertical Rail (Floating):** Floating circular social icons with subtle hover illumination (`box-shadow: 0 0 16px rgba(255, 255, 255, 0.05)`).

## Shapes

The design system is defined by pill geometry (`roundedness: 3`).

- **Capsules & Badges:** Fully rounded pills (`border-radius: 9999px`) used universally for navigation islands, status tags, primary/secondary action buttons, and circular utility triggers.
- **Structural Cards:** Rounded surfaces featuring generous `24px` to `32px` corner radii (`rounded-2xl` to `rounded-3xl`), ensuring outer card curves harmonize with nested pill controls.
- **Floating Floating Dock Buttons:** Exact 1:1 circular aspect ratio (`border-radius: 50%`) with concentric interior icon centering.

## Components

### 1. Navigation Island
- **Structure:** Floating, centered glassmorphic pill bar.
- **Styling:** `rgba(18, 18, 18, 0.75)` backdrop blur (24px) surrounded by an ultra-thin perimeter (`1px solid rgba(255, 255, 255, 0.07)`).
- **Items:** Horizontal link row with active states encased in a pill badge (`#1F1A16` fill with `#FF7A00` label text).
- **Global CTA:** Right-aligned high-contrast primary amber pill with directional arrow icon (`Discutons →`).

### 2. Interactive Buttons
- **Primary Pill:**
  - Background: Linear gradient (`135deg, #FF7A00 0%, #FF8A1A 100%`).
  - Text: `#090909` or high-contrast dark tone, bold weight (`Plus Jakarta Sans 600`), inline chevron/arrow indicator.
  - Hover: Subtle scale transformation (`scale(1.03)`) with magnified amber radiance (`box-shadow: 0 12px 36px rgba(255, 122, 0, 0.45)`).
- **Secondary Glass Pill:**
  - Background: `rgba(255, 255, 255, 0.04)`.
  - Border: `1px solid rgba(255, 255, 255, 0.12)`.
  - Text: `#F5F5F5` accompanied by an inline outline icon (e.g., mail, portfolio link).
  - Hover: Background shifts to `rgba(255, 255, 255, 0.08)`, border illuminates to `rgba(255, 122, 0, 0.3)`.

### 3. Status & Identity Badges
- **Availability Chip:** Floating pill featuring a pulsating amber status dot (`#FF7A00`), text set in `label-eyebrow` uppercase tracking, wrapped in semi-translucent dark glass (`rgba(22, 22, 22, 0.8)`).

### 4. Floating Social Rail
- **Layout:** Vertical column docked left.
- **Nodes:** 40px × 40px circular translucent discs.
- **Icons:** Crisp monochrome (`#A0A0A0`) transitioning on cursor focus to `#FF7A00` with subtle outward glow.

### 5. Metric Stat Cards & Shelves
- **Structure:** Minimalist horizontal stats row separated by hairline dividers (`rgba(255, 255, 255, 0.08)`).
- **Values:** Bold numerical metric (`stat-value`) in `#F5F5F5` with trailing amber symbols (`+`, `%`), paired with stacked subdued descriptions (`#A0A0A0`).
